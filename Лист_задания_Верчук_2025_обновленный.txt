Тема: Web-приложение «Калькулятор для составления сметы на оборудование и работы по электропроводке в жилых помещениях»

1.	Срок сдачи студентом законченной работы: «16 декабря 2025 г.»

2.	Исходные данные к проекту:

2.1.	Функционально веб-приложение должно поддерживать роли «Гость», «Проектировщик», «Администратор».

          Функции пользователя с ролью «Гость»:
          − регистрация;
          − аутентификация.

          Функции пользователя с ролью «Проектировщик»:
          − создание, изменение, удаление проектов электросети;
          − добавление, изменение, удаление жилых помещений в проект электросети;
          − настройка свойств помещений (тип помещения, количество окон, конфигурация розеточных групп с количеством розеток в каждой группе от 2 до 4);
          − просмотр каталога электроприборов;
          − добавление, изменение, удаление списка электроприборов проекта электросети;
          − использование пошагового калькулятора для создания нового проекта электросети с автоматическим расчетом параметров;
          − использование калькулятора для существующих проектов с возможностью точечных изменений;
          − получение расчетной ведомости проекта электросети с учетом коэффициента спроса (Kc) согласно ТКП 339-2022:
            • установленная мощность (сумма всех мощностей электроприборов);
            • коэффициент спроса (0.8 для мощности < 14 кВт, 0.6 для мощности ≥ 14 кВт);
            • расчетная мощность (установленная мощность × коэффициент спроса);
            • расчетный ток (расчетная мощность / 221В);
            • номинал главного автоматического выключателя;
            • расчет трудозатрат (прокладывание проводов, установка УЗО, установка электросчетчика);
            • расчет стоимости монтажных работ;
          − получение сметы электротехнического оборудования, включающей:
            • кабели и провода (ВВГ 3x1.5 мм² для освещения, 3x2.5 мм² для розеток, 3x6 мм² для электроплит) с расчетом длины по эвристике;
            • автоматические выключатели (10А для освещения, 16А для розеток, главный автомат по расчету);
            • УЗО (30мА, обязательное для розеточных групп, ванных комнат, стиральных машин, электроплит);
            • розетки и выключатели;
            • распределительные коробки (1 на комнату или группу розеток);
            • клеммники пружинные (WAGO) для соединения проводов;
            • кабельные клипсы для крепления кабеля;
          − сохранение смет для последующего просмотра и сравнения;
          − просмотр истории сохраненных смет проекта;
          − экспорт расчетной ведомости и сметы оборудования в PDF;
          − отправка расчетной ведомости и сметы оборудования на email;
          − просмотр рекомендаций по соответствию нормам ТКП 339-2022;
          − обновление, удаление личного профиля.

          Функции пользователя с ролью «Администратор»:
          − управление пользователями:
            • просмотр списка всех пользователей системы;
            • просмотр детальной информации о пользователе;
            • создание новых пользователей с назначением ролей (Гость, Проектировщик, Администратор);
            • изменение данных пользователей (имя, email, пароль, роли);
            • удаление пользователей из системы;
          − управление базой электроприборов:
            • просмотр каталога всех электроприборов;
            • добавление новых электроприборов с указанием параметров (название, мощность, напряжение, ток, категория, модель, IP-рейтинг, цвет, цена, марка кабеля, сечение кабеля, габариты, изображение);
            • изменение параметров существующих электроприборов;
            • удаление электроприборов из базы данных;
          − управление типами жилых помещений:
            • просмотр списка всех типов помещений;
            • добавление новых типов помещений с указанием коэффициентов мощности (минимальный и максимальный);
            • изменение параметров типов помещений (название, описание, коэффициенты);
            • удаление типов помещений из системы;
          − управление электрическими символами:
            • просмотр библиотеки электрических символов (розетки, выключатели, светильники и т.д.);
            • добавление новых электрических символов с указанием типа, IP-рейтинга, параметров;
            • изменение параметров существующих символов;
            • удаление символов из библиотеки;
          − просмотр проектов электросети:
            • просмотр списка всех проектов, созданных пользователями системы;
            • просмотр детальной информации о проекте (комнаты, приборы, расчеты);
            • просмотр расчетной ведомости проекта;
            • просмотр сметы оборудования проекта;
          − просмотр статистики:
            • статистика использования электроприборов (количество использований каждого прибора в проектах);
            • статистика по типам помещений;
            • статистика по проектам (общее количество, распределение по проектировщикам);
            • визуализация статистики в виде графиков и диаграмм.

2.2.	Технические требования:

          − расчеты должны соответствовать нормам ТКП 339-2022 (Технический кодекс установившейся практики «Электроустановки жилых и общественных зданий»);
          − использование коэффициентов спроса для расчета нагрузки согласно стандартам;
          − автоматический подбор сечения кабелей, номиналов автоматических выключателей и УЗО;
          − расчет токов утечки для подбора УЗО;
          − валидация требований ТКП 339-2022 (запрет установки розеток в ванных комнатах зон 0, 1, 2; обязательное УЗО для определенных типов помещений и приборов);
          − расчет длины кабелей с использованием эвристических методов (периметр помещения + количество розеток × 3 + 10м) × 1.1;
          − расчет количества расходных материалов (распределительные коробки, клеммники, кабельные клипсы);
          − расчет трудозатрат на монтажные работы (прокладывание проводов, установка УЗО, установка электросчетчика);
          − расчет стоимости монтажных работ с учетом трудозатрат.

2.3.	Дополнительные функции:

          − пошаговый калькулятор для создания проекта с пошаговым вводом данных (выбор типа помещения, добавление электроприборов, настройка розеточных групп);
          − возможность редактирования существующих проектов через калькулятор с сохранением части данных;
          − настройка свойств помещений через модальное окно (тип помещения, количество окон, конфигурация розеточных групп);
          − сохранение смет оборудования для последующего просмотра;
          − просмотр истории сохраненных смет проекта;
          − экспорт расчетной ведомости и сметы оборудования в PDF;
          − отправка расчетной ведомости и сметы оборудования на email пользователя;
          − визуализация расчетной ведомости с отображением всех расчетных параметров;
          − группировка материалов в смете по категориям (кабели, устройства, расходные материалы).
